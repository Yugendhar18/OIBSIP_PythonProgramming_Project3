# 🎙️ Python Voice Assistant (Command Line)

🚀 Just launched my Python-powered Voice Assistant!  
Built for the command line, designed for simplicity, and ready to take voice commands like **hello**, **date**, **time**, **YouTube**, **ChatGPT**, and **Google**.

This beginner-friendly project helped me sharpen my Python skills while exploring real-world applications like voice recognition, text-to-speech, and command execution.

## 🔧 Tech Stack

- Python 3  
- `speech_recognition`  
- `pyttsx3`  
- `datetime`, `webbrowser`, `os`  
- Command Line Interface (CLI)

## 🎯 Features

- 🎤 Voice input recognition  
- 🗣️ Text-to-speech responses  
- 📅 Tells current date and time  
- 🌐 Opens websites like YouTube, Google, and ChatGPT  
- 👋 Responds to greetings like “hello”  
- 🧠 Simple control flow and logic for command handling
